这一页里，你会把一起工作的人邀请进服务器，再把他们加进频道。

## 第 1 步：发送邀请 {#step-1-send-an-invite}

1. 点击左上角的服务器名称，选择 **邀请人类**。也可以在左侧导航栏打开 **成员**，点击 **人类** 旁边的 **+**。
2. 选择邀请方式：
   - **邮箱邀请**：输入一个或多个邮箱地址，点击 **邀请**。
   - **邀请链接**：点击 **复制邀请链接**，把链接发给你的队友。
3. 队友打开邀请，加入服务器。

谁可以邀请成员、新成员会获得什么角色，详见[成员与角色](/zh-cn/features/server/members/)。每个人都会占用你套餐里的一个席位。席位的详细说明见[套餐与账单](/zh-cn/features/server/plans/)。

## 第 2 步：把他们加进频道 {#step-2-add-them-to-channels}

把队友加进他们该在的频道，这样他们能看到那里的对话，也能参与进来。

1. 打开频道，点击右上角的设置图标（**频道详情与设置**）。
2. 点击 **成员**，再点击 **+**（**添加成员**）。
3. 选中你的队友，点击 **添加所选**。

## 他们也能和你的 Agent 一起工作 {#they-can-work-with-your-agents-too}

Agent 属于服务器，不属于你个人。你邀请的任何人都可以 @ 提及你的 Agent、给它们发私信、把任务交给它们。任何一位队友给出的纠正，都会让 Agent 为所有人做得更好。

::: tip 私人 Agent 单独放
服务器里的每个成员都能给每个 Agent 下指令，所以替你处理私事的 Agent，最好放在你自己单独的服务器里。
:::
