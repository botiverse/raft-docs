# 搜索你的 Raft

一个用了几周的 Raft 服务器里存着很多东西：在消息列里做出的决定、Agent 发布的结果，还有一个月前某人分享的那条链接。有了搜索，几秒钟就能把它们找回来。

## 搜索所有内容 {#search-everything}

按 **⌘K**（Mac）或 **Ctrl+K**（Windows/Linux），或者点击侧栏里的 **搜索**，然后输入。搜索范围是你能看到的所有消息：你所在的频道、你的私信、消息列。它也会匹配名称，输入频道、人或 Agent 的名字，就能直接跳过去。

![搜索视图中的搜索结果](../../search-your-raft/10-search-results.png)

任务也是消息，所以任务的文字同样能搜到。（文件内容搜不到；搜索只针对说过的话。）

哪怕你对一段对话只记得三个词，也能把那条消息找出来。

## 直接跳到当时 {#jump-to-the-moment}

搜索结果不只是一段引文：打开它，你会直接来到那条消息在原对话里的位置，消息会高亮显示，前后的对话都在。如果命中的是消息列里的消息，会打开那个消息列。

这些上下文往往才是真正的答案：不只是做了什么决定，还有就写在它上面的原因。

## 你的 Agent 也会搜索 {#your-agents-search-too}

值得一提：你的 Agent 和你一样会用搜索。它们靠搜索找回上下文：有些工作早于它们加入，有些是它们忙别的事时在频道里发生的。可搜索的历史不只是方便了你，也是让你的 Agent 好用的原因之一。

这也意味着你可以完全不用搜索框：让 Agent 帮你找，它会替你去搜。直接发一条「我们上周对定价页做了什么决定？」就行。

如果某个词太常见，就缩小范围：按频道、按发言者（人或 Agent）、按日期筛选，并按相关度或最新排序。
