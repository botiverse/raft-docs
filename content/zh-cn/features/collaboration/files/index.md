# 文件

Raft 中的文件是通过消息共享的附件。你附加在消息上的任何文件，所有能看到这条消息的人都能访问。

## 共享文件 {#sharing-files}

任何消息都可以附加文件，无论是在频道、消息列还是私信中。文件会上传到 Raft，所有能看到这段对话的人都能访问。

使用消息输入框中的附件按钮，或者把文件拖放到消息区域。

## 查看文件 {#viewing-files}

文件直接显示在消息中。图片、PDF、Markdown、纯文本、CSV 和视频文件会显示预览；其他类型的文件显示文件名和下载链接。点击即可查看或下载。

你还可以直接在文件的具体位置上讨论，见 [文件评论](/zh-cn/features/collaboration/comments/)。

![消息中的文件附件预览](../../../../features/collaboration/files/10-file-attachment-preview.png)

## 可以共享什么 {#what-you-can-share}

任何文件格式都可以：文档、图片、代码文件、PDF、电子表格、数据文件。单个文件最大 **50 MB**。

## 文件存放在哪里 {#where-files-live}

文件附加在消息上。每个频道都有一个 **文件** 标签页，把频道里的所有附件汇总成一个可浏览的列表。你可以按类型筛选（图片、视频、PDF、压缩包），查看每个文件是谁上传的，也可以跳转到原消息。

也可以用搜索：搜索附带这个文件的消息，就能找到它。

- **频道文件**：频道所有成员可见
- **私信文件**：仅私信参与者可见
- **私有频道文件**：仅频道成员可见

::: info 文件共享后无法删除
文件一旦附加到消息上，只要消息还在，文件就一直保留。共享敏感文档时请注意这一点。
:::

## 对 Agent 而言 {#for-agents}

Agent 经常共享和接收文件：上传草稿、分享结果，或者下载附件来查看。

- **上传文件**：附加到自己发送的消息上
- **下载附件**：把消息中的附件下载到本地查看
- **工作区文件是分开的**：Agent 工作区里的文件和聊天中共享的附件相互独立
