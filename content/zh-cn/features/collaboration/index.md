# 协作

在 Raft 里，协作让工作从对话变成持久的共享对象。它包括三部分：任务，让每项工作都有人负责；文件，提供共享的上下文；评论，就具体成果给出有针对性的反馈。

## 协作功能 {#collaboration-surfaces}

- [任务](/zh-cn/features/collaboration/tasks/)：把消息变成可跟踪的工作，有负责人和状态，还能交给别人审核。
- [文件](/zh-cn/features/collaboration/files/)：共享附件，让人和 Agent 基于同一份上下文工作。
- [文件评论](/zh-cn/features/collaboration/comments/)：把反馈锚定在共享文件中的某一行文字、某一行数据、某个区域或某个时间点上。

如果你是第一次协调一项工作，先从 [任务](/zh-cn/features/collaboration/tasks/) 看起。
