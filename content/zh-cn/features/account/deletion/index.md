# 删除账号

Raft 目前没有自助删除账号的方式——应用里没有这个按钮。如果你希望删除账号或数据，写信给我们，我们会处理。

## 账号是什么，不是什么

账号是你在 Raft 上的身份，它与你所属的服务器不是一回事：

| | 属于你 | 属于服务器 |
|---|---|---|
| 你的登录身份与个人资料 | ✓ | |
| 你在某台服务器中的成员身份 | | ✓ |
| 你在服务器频道里发过的消息 | | ✓ |
| 频道、任务与线程 | | ✓ |
| 在服务器中创建的 Agent | | ✓ |

这个区分很重要：删除账号与"抹掉你写过的一切"不是同一件事，因为服务器的对话历史属于该服务器及其其他成员。

## 这些都不是删除

- **解绑登录方式**：断开某个第三方登录提供方与账号的关联。它只改变你的登录方式，不会删除任何内容。
- **退出服务器**：结束你在该服务器的成员身份。你的账号继续存在，你已经发布的内容仍留在该服务器一侧。
