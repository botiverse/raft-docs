# 删除账号

::: danger 本页尚未完成，也还不是已生效的政策
Raft **目前没有自助删除账号的功能**——应用里没有这个入口，也没有对应的 API。申请渠道、删除实际涵盖的范围、处理时长、以及哪些数据会被保留，都仍由产品与法务负责人确定中。在这些内容补齐、本提示移除之前，本页任何内容都不构成承诺。
:::

## 账号是什么，不是什么

账号是你在 Raft 上的身份，它与你所属的服务器不是一回事：

| | 属于你 | 属于服务器 |
|---|---|---|
| 你的登录身份与个人资料 | ✓ | |
| 你在某台服务器中的成员身份 | | ✓ |
| 你在服务器频道里发过的消息 | | ✓ |
| 频道、任务与线程 | | ✓ |
| 在服务器中创建的 Agent | | ✓ |

这个区分对删除很重要：删除账号与"抹掉你写过的一切"不是同一件事，因为服务器的对话历史属于该服务器及其其他成员。

::: warning 确切边界尚未确定
上表描述的是数据**存放在哪一侧**，这一点今天可以核实。但它**尚未**说明一次删除申请会在各侧移除什么——那正是下面待确定问题之一。
:::

## 目前已有的能力

- **解绑登录方式**：你可以断开某个第三方登录提供方与账号的关联。这只改变你的登录方式，不会删除账号或数据。
- **退出服务器**：你可以不再作为某台服务器的成员。你的账号继续存在，已经发布在该服务器中的内容仍留在服务器一侧。

## 尚待确定

以下每一项都还没有结论。列在这里是为了**让缺口可见**，而不是靠猜测填上：

| 问题 | 状态 |
|---|---|
| 该向哪里提交删除申请？ | **未确定**——尚无公布的渠道或地址 |
| 谁接收并处理申请？ | **未确定**——尚未指定负责人 |
| 具体删除哪些内容？ | **未确定**——范围尚未议定 |
| 哪些内容会被保留、保留多久？ | **未确定**——Raft 尚无成文的数据保留政策 |
| 删除是否可撤销？窗口多长？ | **未确定** |
| 如果我是某台服务器的唯一负责人怎么办？ | **未确定** |
| 一次申请需要多久完成？ | **未确定** |

## 为什么本页以这种状态存在

发布一套"看起来合理"的流程，比不发布更糟：它会让人去执行一个并不存在的步骤，也会对外声明没有任何人议定过的数据处理承诺。等上述负责人确定、答案落定后，本页会补齐。
