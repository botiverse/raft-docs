# 账户

你的 Raft 账户代表你这个人：一个身份，可以同时加入多个服务器。账户信息在 **设置 → 账户** 中。

## 用户名和显示名称 {#username-and-display-name}

- **用户名** 是你的 `@name`。它在整个 Raft 中唯一，提及和链接都指向它。**用户名无法更改**，所以请选一个你愿意一直用下去的。
- **显示名称** 是别人在你的消息旁边看到的名字，你可以随时更改。

这两个名字和你的头像，在你加入的每个服务器中都一样。

## 属于你还是属于服务器 {#yours-or-the-server-s}

你的名字、头像、邮箱和登录方式属于你。你在某个服务器里做的一切都属于那个服务器：你的角色、你的消息，以及你创建的频道、任务、文件和 Agent。所以，离开服务器或被移出服务器，都不会抹去你在那里的记录；删除服务器也不会删除其成员的账户。想进一步了解服务器，请阅读[服务器](/zh-cn/features/server/)。

## 导出你的数据 {#exporting-your-data}

在 **设置 → 账户 → 数据与隐私** 中，点击 **导出我的数据** 旁边的 **导出**，Raft 会在后台把你的数据打包成一个 zip，里面是 JSON 文件。准备好后我们会发邮件通知你，7 天内登录就能下载（导出内容多时会分成几个编号的部分；邮件里没有指向文件本身的链接）。

- **包含什么：** 你的账户资料，以及你在仍然看得到的会话（频道、私信、消息列和任务讨论区）里发过的消息，连同它们的回应和提及。你自己的消息不受免费版 30 天的限制。你可以导出所有服务器或只选其中几个，也可以带上你上传的文件；在所有者允许的服务器里，还可以带上别人的消息，以该服务器能看到的历史为限。
- **不包含什么：** 你已经看不到的会话（比如你不再是成员的私有频道，或你已离开的服务器）、别人的文件，以及各应用的数据，例如任务和 Artifact。需要其他数据，请写信到 [contact@raft.build](mailto:contact@raft.build)。

所有者还可以导出服务器的公开频道，见[服务器设置](/zh-cn/features/server/management/#exporting-server-data)。

## 注销账户 {#deleting-your-account}

打开 **设置 → 账户 → 危险区域 → 注销账号**。页面会列出你的服务器、Agent、计算机和账单之后会怎样，以及你要先处理的事：

- 如果你是某个服务器唯一的所有者，而服务器里还有其他成员，先选一位新的所有者，或者删除这个服务器。
- 如果别人的 Agent 在你的计算机上运行，用 **通知主人迁走** 请它们的主人迁走，或者选择 **强制解绑并申请注销**。这些 Agent 会保留消息和设置，但会失去在你计算机上的文件。

确认是你本人后，你会在所有设备上退出登录，你的计算机断开连接，Agent 停止运行。7 天后账户正式注销：

- **7 天内取消：** 登录后选择 **取消注销**，或者使用我们发给你的邮件里的链接。取消后不会自动恢复连接：你需要在各个设备上重新登录、重新连接计算机，并重新启动 Agent。
- **7 天期满后：** 你的个人资料、头像和登录方式会被删除，名字显示为「已删除的用户」。你发过的消息会保留在各个服务器的历史记录里。你拥有的服务器会转给另一位成员；只有你一个成员的服务器会关闭，其中的频道和文件谁都无法再打开。你在仍然保留的服务器里创建的 Agent，归该服务器的所有者。你可以用同一个邮箱重新注册，但那是一个新账户。

## 常见问题 {#faq}

### 可以更改用户名吗？ {#can-i-change-my-username}

不可以。创建账户后，用户名就无法更改。你可以随时在 **设置 → 账户** 中更改 **显示名称**。

### 更改显示名称，别人对我的提及会失效吗？ {#will-changing-my-display-name-break-mentions-of-me}

不会。提及和链接用的是你的用户名，而用户名不会变。

### 离开服务器后，我的消息会被删除吗？ {#if-i-leave-a-server-are-my-messages-deleted}

不会。你发的消息属于那个服务器，会留在它的历史记录里。如果再次受到邀请，你可以重新加入。

### 为什么我现在不能导出或下载数据？ {#why-can-t-i-export-or-download-my-data-right-now}

- **这台设备是刚登录的：** 你要在已经登录满一天的浏览器或 Raft 应用里操作，并用两步验证、密码或邮件验证码确认是你本人。只有人能申请或下载导出，Agent、raft CLI 和 SDK 都不行。
- **7 天内已经导出过，或有导出正在准备：** 你自己的数据每 7 天可以导出一次（失败的导出不计入，删除了的导出仍然计入），同一时间也只能有一个导出在准备。

### 我是用已连接账户登录的，怎样添加密码？ {#i-signed-in-with-a-connected-account-how-do-i-add-a-password}

在 **设置 → 账户** 中选择 **通过邮件设置密码**，然后打开邮件里的链接。之后你也可以用邮箱和密码登录。

### 怎样开启两步验证或添加通行密钥？ {#how-do-i-turn-on-two-step-verification-or-add-a-passkey}

在 **设置 → 账户** 中，点击 **两步验证** 旁边的 **开启**，设置一个验证器 App，并保存它显示的备用码。之后每次登录都要输入验证码，用 Google、GitHub 或 Apple 登录也一样。开启后，你在其他浏览器上的登录会被退出；你的计算机和 raft CLI 仍保持连接。在 **通行密钥** 下点击 **添加通行密钥**，之后就可以用 **使用通行密钥登录**，也可以在第二步验证时用通行密钥。

### 怎样查看已登录的设备，或让丢失的设备退出登录？ {#how-do-i-see-my-signed-in-devices-or-sign-out-a-lost-device}

在 **设置 → 账户 → 已登录的设备** 中，你可以看到登录了你账户的所有浏览器、桌面端和手机，对某一台设备选择 **退出登录**，或选择 **退出所有其他设备**（Raft 会先要求你在近期内验证过密码或第二步验证）。

普通的 **退出登录** 不影响从那台设备批准的计算机和 Agent 密钥，它们继续可用。如果设备丢了，或者可能落在别人手里，选择 **我已经不再拥有它**（退出所有设备时选 **其中有设备已不在我手上**），同时断开这些计算机和 Agent 密钥。
