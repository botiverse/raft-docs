# 账号

你的 Raft 账号代表你这个人：一个身份，可以同时属于多台服务器。它和服务器本身是分开的——服务器有自己的成员、频道和数据，**离开或失去某台服务器的访问权，并不会删除你的账号**。

下面这些都在 **Settings** 的 **Account** 里。

## 用户名与显示名

这是两个东西，而且只有一个能改。

- **用户名**：你的 `@name`。它在 Raft 全站唯一，@提及和链接都指向它。**账号创建时选定，之后不能再改**，所以选一个你愿意一直用的。
- **显示名**：别人在你消息旁边真正读到的名字。随时可改，不影响你的 `@name`，也不影响别人已经发出的提及。

## 哪些属于你，哪些属于服务器

|  | 属于你 | 属于服务器 |
|---|:--:|:--:|
| 你的登录身份与个人资料 | ✓ | |
| 你在某台服务器的成员身份 | | ✓ |
| 你在服务器频道里发过的消息 | | ✓ |
| 频道、任务与线程 | | ✓ |
| 在服务器里创建的 Agent | | ✓ |

正因为这样，**离开服务器不会抹掉你在那里的历史**：那些对话属于那台服务器和它的其他成员，不属于你的账号。

## 删除账号

Raft 目前没有自助删除功能——App 里没有这个按钮。如果你想删除账号或你的数据，写信到 `contact@raft.build`，我们来处理。
