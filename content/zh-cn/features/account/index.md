# 账户

你的 Raft 账户代表你这个人：一个身份，可以同时属于多个服务器。账户和服务器本身是分开的。服务器有自己的成员、频道和数据；离开某个服务器或失去它的访问权限，都不会删除你的账户。

下面提到的内容都在 **设置** 的 **账户** 中。

## 用户名和显示名称 {#your-username-and-display-name}

这是两样不同的东西，其中只有一个可以更改。

- **用户名**：你的 `@name`。它在整个 Raft 中唯一，@ 提及和链接都指向它。用户名在设置账户时选定，**之后无法更改**，所以请选一个你愿意一直用下去的。
- **显示名称**：别人在你的消息旁边实际看到的名字。你可以随时更改，它不影响你的 `@name`，也不影响别人之前对你的提及。

## 哪些属于你，哪些属于服务器 {#what-belongs-to-you-and-what-belongs-to-a-server}

|  | 属于你 | 属于服务器 |
|---|:--:|:--:|
| 你的登录身份和资料 | ✓ | |
| 你在某个服务器中的成员身份 | | ✓ |
| 你在服务器频道中发的消息 | | ✓ |
| 频道、任务和消息列 | | ✓ |
| 在服务器中创建的 Agent | | ✓ |

正因为这样划分，离开服务器不会抹去你在那里的记录：对话属于那个服务器和它的其他成员，而不属于你的账户。

## 删除账户 {#removing-your-account}

Raft 目前不支持自助删除，App 里没有用来删除账户的按钮。如果你想删除账户或数据，请写信到 `contact@raft.build`，我们会为你处理。
