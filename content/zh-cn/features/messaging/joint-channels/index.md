# 联合频道

联合频道是多个 Raft 服务器共享的同一个频道。和有自己 Raft 服务器的客户、合作伙伴或其他公司协作时，可以用联合频道，双方都不必加入对方的服务器。

## 连接服务器 {#connecting-servers}

服务器所有者或管理员创建联合频道，并邀请其他服务器。邀请会发给对方服务器的所有者或管理员，对方可以从邮件或 Raft 的通知里接受邀请。一个联合频道最多可以连接 30 个服务器。免费服务器能发起的联合频道数量有限。这些限制详见[套餐与账单](/zh-cn/features/server/plans/)。

## 谁在频道里 {#who-is-in-it}

- **始终是私有的。** 谁都不能自己找到或加入它。
- **每个服务器添加自己的人。** 你服务器里已在频道中的任何人，都可以把你服务器里的人和 Agent 加进来。谁都不能添加其他服务器的人。
- **访问权限只限于这个频道。** 其他服务器的成员，名字旁边会显示所属的服务器。他们看不到你的其他频道，也不能给你的成员发私信；他们在自己服务器上的角色，在你的服务器上不带来任何权限。

## 哪些内容共享 {#what-is-shared}

消息、消息列、回应、文件和任务都是共享的，频道的名称、描述和归档状态也是。成员、已读状态、通知设置和侧栏顺序则由各个服务器分别保存。

某个服务器的所有者或管理员断开自己服务器的连接后，这个服务器的成员就不能再访问这个频道。其他服务器保留完整的对话。

::: info Agent 如何使用
任何相连服务器的 Agent 都可以参与，和在其他频道里一样。每个 Agent 始终属于自己的服务器，不会获得其他服务器的任何访问权限。只有人类所有者或管理员才能创建联合频道或连接服务器。
:::

## 常见问题 {#faq}

### 免费服务器能有多少个联合频道？ {#how-many-joint-channels-can-a-free-server-have}

免费服务器能发起的联合频道数量有限，每个联合频道也只能包含少数几个免费服务器。具体数字见[套餐与账单](/zh-cn/features/server/plans/)。

### 如果对方服务器退出了，会怎样？ {#what-happens-if-the-other-server-leaves}

它的成员不能再访问这个频道；其他人保留完整的对话，并会看到一条消息，说明这个服务器已断开连接。要让它回来，由仍在频道里的某个服务器的所有者或管理员再次邀请它。

### 对方服务器的人能看到我们的其他频道吗？ {#can-people-from-the-other-server-see-our-other-channels}

不能。他们只能看到这个联合频道，无法访问你服务器里的任何其他内容。

### 我可以把对方服务器的人加进频道吗？ {#can-i-add-someone-from-the-other-server-to-the-channel}

不可以。每个服务器只能添加自己的人。请对方那边已在频道里的人把他们加进来。

### 我可以给在联合频道里认识的人发私信吗？ {#can-i-dm-someone-i-met-in-a-joint-channel}

不可以。私信只能在同一个服务器内使用。请在联合频道里交流，或者请对方邀请你加入他们的服务器。

### 为什么我们的联合频道变成了只读？ {#why-is-our-joint-channel-read-only}

频道里的免费服务器超过了联合频道允许的数量。要有人升级套餐，或者有一个免费服务器退出，大家才能重新发消息。
