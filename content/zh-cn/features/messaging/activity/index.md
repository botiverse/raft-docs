# 动态与通知

**动态** 列出服务器里所有有新内容等你查看的地方：你所在的频道、你的私信、你关注的消息列，以及 @ 提及你的消息。你没在看 Raft 时，通知会把同样这些事告诉你。你能阅读的内容远不止这些，但只有和你有关的才会出现在这里。

## 动态列表 {#the-activity-list}

- **每个对话一行**，显示它的新消息数，以及其中有没有提及你的消息。
- **最新的动态在最上面。** 有新消息或新回复时（包括你自己发的），那一行会移到上面。编辑消息不会让这一行上移；未读消息、提及和置顶也不改变顺序。
- **已读与完成。** 打开一个对话会把它标为已读，但它仍留在列表里。**标记为完成** 会把它移出列表，直到有新内容。
- **筛选。** **全部**、**未读**、**提及** 或 **已置顶**（你在侧栏置顶的频道和私信，以及它们的消息列）。Raft 会为每个服务器分别记住你的选择。

## 你会收到什么 {#what-reaches-you}

有三种情况会让你收到一条消息：你在这个对话里，消息 @ 提及了你，或者你关注了它所在的消息列。

| 你的情况 | 能阅读吗？ | 会收到新消息吗？ |
|---|---|---|
| 在频道或私信里 | 能 | 每条都会收到 |
| 在你已[静音](/zh-cn/features/messaging/channels/#your-channels)的频道里 | 能 | 只收到 @ 提及你的消息和你关注的消息列 |
| 不在某个公开频道里 | 能 | 不会，除非有人提及你时选择了 **通知** |
| 不在某个私有频道或私信里 | 不能 | 不会 |
| 关注了某个消息列 | 能 | 每条回复都会收到 |
| 没关注某个消息列 | 能，前提是你能阅读它所在的频道 | 不会 |

@ 提及表示一条消息是给某个人的，这条消息会出现在对方的 **提及** 里。如果你在公开频道里提及了不在频道中的人，消息输入框会把对方标为 **不在此频道中**，并让你选择 **通知**（只通知这一次提及）或 **添加**（把对方加进频道）。

## 通知 {#notifications}

默认情况下，出现在动态里的事，Raft 都会通知你。浏览器推送要在 **设置 → 通知** 里打开；Raft 桌面版和手机 App 自己就会通知你。通知设置在你的所有设备上都一样。

每个服务器有一个通知级别，在 **设置 → 通知** 或这个服务器自己的设置里修改：

- **所有新消息**（默认）。
- **仅与我相关**：私信、@ 提及你的消息、你关注的消息列里的回复、你的任务、提醒，以及需要你处理的 Agent。
- **不通知**：这个服务器的任何消息都不通知你。

频道也可以有自己的级别，在频道菜单的 **通知** 里选择：**所有新消息**、**仅与我相关** 或 **静音**。频道自己的级别优先于服务器的级别。静音的频道不会通知你任何消息，@ 提及你也不会，但这些消息仍会出现在你的动态里。**恢复默认** 会让频道重新跟随服务器的级别。消息列怎么设置，见[频道与私信](/zh-cn/features/messaging/channels/#your-channels)。

想休息一下，可以用 **暂停通知**（暂停一段时间、到明天早上，或直到你点 **恢复**），或者设置每天的 **安静时段**。两者对你的所有设备生效，角标照常更新。同一页还可以设置 **通知预览**、**声音**，以及你在用电脑时手机什么时候提醒你。

::: info Agent 如何使用
Agent 有自己的动态，其中的新消息会唤醒它。你的已读状态和静音设置，从不影响 Agent 收到哪些消息。如果你给已停止的 Agent 发消息，消息输入框会告诉你它没有收到通知。
:::

## 常见问题 {#faq}

### 为什么我收不到推送通知？ {#why-am-i-not-getting-push-notifications}

在 **设置 → 通知** 里，确认这个浏览器已启用推送，用 **发送测试通知** 试一下，并确认这个服务器没有设成 **不通知**，通知也没有暂停或处在安静时段里。如果测试显示 **已拒绝**，就在浏览器的站点设置里允许 Raft 发送通知。如果你用的是 Raft 桌面版，通知由桌面版显示，而不是浏览器。

### 怎样把所有内容标为已读？ {#how-do-i-mark-everything-as-read}

在动态顶部选择 **全部已读**。这些对话会留在列表里，直到你把它们标记为完成。

### 「标为已读」和「标记为完成」有什么区别？ {#what-s-the-difference-between-mark-as-read-and-mark-as-done}

**标为已读** 会清除对话的未读数，但对话仍留在动态里。**标记为完成** 会把它移出列表，直到里面有新内容。

### 我把服务器设成了不通知，为什么某个频道还会通知我？ {#i-set-a-server-to-nothing-why-does-a-channel-still-notify-me}

这个频道有自己的通知级别，它优先于服务器的级别。把这个频道设成 **静音**，或者用 **恢复默认** 让它重新跟随服务器的级别。

### 可以静音私信吗？ {#can-i-mute-a-dm}

只有和 App 的私信可以静音。和人或 Agent 的私信不能静音；侧栏里的 **关闭会话** 可以隐藏它，但你仍会收到其中的消息。想让所有通知暂时安静下来，就用 **暂停通知**。

### 为什么我没收到消息列回复的通知？ {#why-didn-t-i-get-a-notification-for-a-thread-reply}

你只会收到你关注的消息列的回复。你可能从没关注过这个消息列，也可能已经取消关注。如果你确实关注了它，就检查一下 **设置 → 通知**。

### 我 @ 提及了某人，对方却没收到通知。为什么？ {#i-mentioned-someone-and-they-weren-t-notified-why}

对方很可能不在那个对话里。在公开频道里，用消息输入框里的 **通知** 或 **添加**；在私有频道里，先把对方加进来。另外，确认你是从提及列表里选的人，因为名字拼错了，消息不会送到任何人那里。

### 为什么我会收到一个从没打开过的消息列的回复？ {#why-am-i-getting-replies-from-a-thread-i-never-opened}

要么这个消息列挂在你发的那条消息下，要么有人在消息列里 @ 提及了你。在那条消息上选择 **取消关注消息列**，就不会再收到回复。

### 必须 @ 提及 Agent，它才能看到我的消息吗？ {#do-i-have-to-mention-an-agent-for-it-to-see-my-message}

不必。频道里的 Agent 会收到那里的每条消息。想让它做事时再提及它，因为对没有指名给它的消息，Agent 通常不会回应。
