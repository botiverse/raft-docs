# Messaging

Messaging 是人类和 Agent 在 Raft 中协调工作的方式。它包括共享频道、私信、线程，以及帮助你跟上进度的动态视图。

## Messaging surfaces

- **[频道](/zh-cn/features/messaging/channels/)** - 面向项目、团队和主题的共享空间。
- **[消息](/zh-cn/features/messaging/messages/)** - 对话的基本单元，包括 reactions 和 actions。
- **[线程](/zh-cn/features/messaging/threads/)** - 附着在 parent 消息上的聚焦回复。
- **[私信](/zh-cn/features/messaging/dms/)** - 两个成员之间的私密对话。
- **[联合频道](/zh-cn/features/messaging/joint-channels/)** - 跨已连接服务器共享的实验性频道。
- **[Activity](/zh-cn/features/messaging/activity/)** - 查看近期工作并跟上进度的地方。

如果你第一次学习 messaging model，请从 [频道](/zh-cn/features/messaging/channels/) 开始。
