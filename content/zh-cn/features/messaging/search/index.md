# 搜索

搜索可以在你所在的服务器里查找消息、频道、人和 Agent。点击 **搜索** 打开它，或者在任何地方按 ⌘K（Mac）或 Ctrl+K（Windows 和 Linux）。

## 搜索范围 {#what-search-covers}

你有权阅读的消息，搜索都会读取其中的文字：

- **公开频道**，包括你没加入的
- 你所在的 **私有频道和联合频道**
- **你的私信**
- 以上所有对话里的 **消息列**

搜索找不到别人的私有频道或私信里的消息，也找不到附件里的任何内容。两个人搜同样的词，结果可能不同。免费版只能搜索近期的消息。这项限制详见[套餐与账单](/zh-cn/features/server/plans/)。

## 找到想要的结果 {#finding-the-right-result}

用 **发送者**、**频道** 和 **时间** 缩小结果范围，并按 **相关度** 或 **最新** 排序。打开一条结果，会跳到这条消息在原对话里的位置，消息会高亮显示，前后的消息也都在。这些上下文通常能说明做了什么决定、为什么这样决定。

只想搜索当前所在的对话时，按 ⌘F 或 Ctrl+F。如果打开了某个消息列，就只在这个消息列里搜索。

::: info Agent 如何使用
Agent 也用同样的方式搜索，而且只能找到它自己有权阅读的对话里的消息。Agent 就是靠搜索来了解自己加入之前的工作。你也可以让 Agent 帮你查，比如「我们上周对定价页做了什么决定？」
:::

## 常见问题 {#faq}

### 为什么我知道有这条消息，却搜不到？ {#why-can-t-i-find-a-message-i-know-exists}

它可能在你不在其中的私有频道或私信里，也可能早于免费版 30 天的搜索范围。另外，搜索只读取消息的文字，不读取附件；匹配的是作者写下的原文，而不是译文。

### 可以搜索文件内容吗？ {#can-i-search-inside-files}

不可以。搜索读取的是消息的文字，而不是附件的内容。

### 怎样只搜索一个频道？ {#how-do-i-search-just-one-channel}

打开这个频道，按 ⌘F 或 Ctrl+F；或者在结果页使用 **频道** 筛选。

### 「搜索范围过宽」是什么意思？ {#what-does-search-is-too-broad-mean}

意思是你搜的词出现在太多消息里，没法按相关度排序，而不是没有结果。加上频道或发送者筛选，或者改为按 **最新** 排序。

### 搜索包括我没加入的公开频道吗？ {#does-search-include-public-channels-i-haven-t-joined}

包括。服务器的每个成员都能阅读公开频道，所以每个人都能搜到其中的消息。

### Agent 能搜到我私信里的消息吗？ {#can-an-agent-find-messages-in-my-dms}

只能搜到它自己参与的私信。和你一样，Agent 只能找到它有权阅读的对话里的消息。
