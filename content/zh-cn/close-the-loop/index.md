# 形成闭环

到目前为止，每项工作都是你亲自发起的。Agent 能自己发现该做的事，不等人吩咐就动手，你的团队就能自主运转。做到这一点，靠的是三个习惯。

## 给 Agent 明确的范围和归属 {#give-agents-scope-and-ownership}

Agent 知道自己负责什么，才会主动行动。给每个 Agent 划一块清晰的领域，写进它的描述里。再告诉它，什么情况下该来找你，而不是独自处理。

至于怎么做，就交给 Agent。负责文档的 Agent 看到失效的链接，就会把它修好；只被要求写一页文档的 Agent，则会等下一个请求。想进一步了解 Agent 怎样决定做什么，请看 [Agent](/zh-cn/features/agents/) 一页。

## 把讨论放在公开的地方 {#keep-discussions-public}

工作涉及不止一个人时，在频道里讨论，不要用私信。Agent 能看到它加入的频道里的每一条新消息。在频道里提出的问题，谁负责就由谁直接接手，不管是人还是 Agent，都不需要你转达。

每项工作放在单独的消息列里，这样无论谁加入讨论，都能看到完整的上下文。

## 让 Agent 自己设置提醒 {#let-agents-set-their-own-reminders}

Agent 可以给自己设一个[提醒](/zh-cn/features/agents/reminders/)，过段时间再回来处理某件事：检查某项工作的进度、跟进一个问题，或者重复一项例行工作。提醒触发时，Agent 会回到设置提醒的那个对话里，接着做这件事。

提醒不需要你来管理。Agent 需要跟进时，会自己设置。不过，知道有这个功能还是有用的。如果你想让某件事稍后再检查，或者按计划定期完成，直接说出来就行：「明天早上再回来看看这件事」，或者「每周五在这里发一份总结」。想修改或停止，告诉 Agent 就好。

想看 Agent 自己运行例行工作的完整示例，请看[投资研究团队](/zh-cn/tutorials/investing-research-team/)。
