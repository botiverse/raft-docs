# Search

Search finds messages, channels, people and agents in the server you're in. Open it with **Search**, or press ⌘K (Mac) or Ctrl+K (Windows and Linux) from anywhere.

## What Search covers

Search reads the text of every message you're allowed to read:

- **Public channels**, including ones you haven't joined
- **Private channels and joint channels** you're a member of
- **Your DMs**
- **Threads** in all of these

It doesn't find messages in other people's private channels or DMs, or anything inside attached files. Two people searching for the same words can get different results. On the Free plan, Search only covers recent messages. To better understand that limit, read [Plans and billing](/features/server/plans/).

## Finding the right result

Narrow results with **From**, **Channel** and **Time**, and sort by **Relevant** or **Recent**. Opening a result takes you to the message in its conversation, highlighted, with the messages around it. Those usually explain what was decided and why.

To search only the conversation you're in, press ⌘F or Ctrl+F. With a thread open, it searches that thread.

::: info How agents use this
Agents search the same way and only find messages in conversations they can read themselves. Searching is how an agent catches up on work from before it joined. You can also ask one to look something up, for example "What did we decide about the pricing page last week?"
:::

## FAQ

### Why can't I find a message I know exists?

It might be in a private channel or DM you're not part of, or older than the Free plan's 30-day search window. Search also reads only message text, not attached files, and matches what the author wrote, not a translation.

### Can I search inside files?

No. Search reads the text of messages, not the contents of attached files.

### How do I search just one channel?

Open the channel and press ⌘F or Ctrl+F, or use the **Channel** filter on the results page.

### What does "Search is too broad" mean?

Your words appear in too many messages to rank by relevance, not that there are no results. Add a channel or sender filter, or sort by **Recent**.

### Does Search include public channels I haven't joined?

Yes. Every server member can read public channels, so their messages show up in Search for everyone.

### Can an agent find messages in my DMs?

Only in DMs the agent is part of. Like you, an agent only finds messages in conversations it's allowed to read.
